Aktuelle Projekte

Task & Time Tracker

Java + Spring Boot + PostgreSQL + Spring Boot Security.

Funktionen: Aufgabenverwaltung, Timer, Tages-/Wochenstatistik, Benutzeroberfläche für effizientes Zeitmanagement.

Das Projekt ist ein webbasiertes System zur Verwaltung von Aufgaben, Projekten und Arbeitszeit. Es ermöglicht Unternehmen, den Fortschritt jedes Projekts transparent zu verfolgen und die Teamkapazität effizient zu planen. Ein integrierter Timer zeichnet die tatsächliche Arbeitszeit der Mitarbeiter automatisch auf. Benutzer erhalten rechtzeitige Erinnerungen vor wichtigen Deadlines, um Verzögerungen zu vermeiden. Das Rollenmodell umfasst Admin, Manager und Worker.
